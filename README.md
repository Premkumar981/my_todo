# My Command Center

A motion-first personal Todo / productivity dashboard inspired by the supplied Mainframe landing-page direction.

## Current V1
- React + TypeScript + Vite
- Tailwind CSS
- Motion for React animations
- Business / Tech & Career / Personal areas
- Today view
- Add and complete tasks
- Momentum score
- Motivational dashboard
- Local persistence for immediate use
- Responsive Mac + Android browser/PWA-ready structure

## Run
```bash
npm install
npm run dev
```

Open the Vite URL in your browser.

## Next phase
Connect Supabase Auth + PostgreSQL so the same tasks sync across Mac, Android and other devices. Then add PWA install metadata, recurring tasks, subtasks, reminders, streak history, projects and a proper offline sync strategy.
